# LonghornNetwork

LonghornNetwork is a social networking application designed around the university student experience. It allows students to explore their connections, discover potential roommates, and find networking paths to peers with internship experience at companies they're interested in.

## Features

- **Student Network Visualization:** Explore student relationships through an interactive graph.
- **Roommate Matching:** Match students based on their preferences using the Gale-Shapley algorithm.
- **Internship Referrals:** Discover networking paths to students who have interned at specific companies using Dijkstra's algorithm.
- **Social Interactions:** Simulate friend requests and messaging between students.

## Tech Stack

- **Frontend:** React, JavaScript, CSS
- **Backend:** Java, REST APIs
- **Core Concepts:** Graph algorithms, stable matching, multithreading
